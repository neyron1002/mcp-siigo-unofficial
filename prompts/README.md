# Prompts

- `prompts/<date>_<topic>/`: reviewed prompts, published. The refined plans (`*_refined_*_vN.md`), the decisions in them, and the execution logs.
- `prompts/raw/`: the owner's raw prompts, word for word. Private: ignored by git, kept only on the owner's computer. Raw prompts committed before 2026-11-20 remain in the repository history.

The rule is in [CLAUDE.md](../CLAUDE.md) (rule 6).
