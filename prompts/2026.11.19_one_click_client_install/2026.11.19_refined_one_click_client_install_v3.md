## 2. Review of the answers

- **Consistent with the write approval plan.** Q2c = A keeps the HTTP server that the stdio approval link uses. Q9 = A puts `v0.2.0` after `v0.1.1` and `v0.1.2`.
- **Two changes without a click:** Q14 (repair) and Q13 (disconnect at uninstall). Both touch only entries that start our launcher, and both keep backups, so this matches Q4 ("nothing changes without a click") for other programs' settings.
- **Q2e stores a token.** The Siigo token is saved in the encrypted vault, next to the credentials that are already there. It is never returned by a tool, printed, or logged (rule 4). Tests check this.
- No new runtime dependency or Qt module is needed (rule 2).
