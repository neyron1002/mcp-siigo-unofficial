- Decisions taken in the build:
  - The app's own command is used **for stdio only**. HTTP entries are always written to the file, so the private key never appears on a process command line. Every command result is checked by reading the settings back; a file edit is the fallback (Q5).
  - On Windows, `.cmd`/`.bat` wrappers (npm installs) are not run, because batch files re-parse their arguments; the settings file is edited instead.
  - Codex HTTP uses `url` + `http_headers` (from the Codex documentation; Codex is not installed in the container).
- Command syntax: `claude mcp add --scope user <name> -- <command> <args…>` and `claude mcp remove --scope user <name>` verified with Claude Code 2.1.327 (end to end in a temporary home). `codex mcp add <name> -- <command…>`, `gemini mcp add --scope user <name> <command> -- <args…>`, and `code --add-mcp '<json>'` follow their documentation (not installed here); a wrong syntax falls back to the file edit.
