# Execution log — Windows startup error (v0.2.1)

Branch `fix-windows-no-console`, from `main` 1dcef55 on 2026-11-27.

## Cause

The Windows app is a window build (PyInstaller `console=False`). Opened from Explorer, the Start menu, or at login, it has no console, so Python sets `sys.stdout` and `sys.stderr` to `None`. `HttpServerThread` built a `uvicorn.Config` with uvicorn's default logging config, whose color formatter calls `sys.stdout.isatty()`: `AttributeError`, reported by `logging.config.dictConfig` as `ValueError: Unable to configure formatter 'default'`. `AppRuntime.start_server()` did not catch it, so the app closed. CI did not see it: the smoke test starts the app with pipes, and macOS and Linux always have a stdout.

## Changes

- `server/transport.py`: `uvicorn.Config(log_config=None, use_colors=False)`; uvicorn keeps the app's logging.
- `__main__.py`: `setup_logging()`. With no console, missing streams point to `os.devnull`; warnings and uncaught errors go to `logs/app.log` in the data folder (rotating, 1 MB, one older file). `paths.log_path()`.
- `app/runtime.py`: `start_server()` catches any exception; the tray shows "stopped" with the error instead of closing.
- Tests: `test_http_server_starts_without_console` (failed with the exact error before the fix), `tests/test_logging_setup.py`, `test_server_error_is_reported_not_raised`.
- `packaging/smoke_test.py`: on Windows, starts the installed app with `--serve` and no streams (as Explorer does) and expects HTTP 401. It uses its own data folder: the smoke test's null keychain keeps no vault key, so the vault from the earlier steps cannot be opened again (found on the first local run, through the new `logs/app.log`).
- Docs: troubleshooting entry, `logs/app.log` in "Where your data is". Version `0.2.1`.

## Verification (Windows host, `.venv` with Python 3.12.10 and uv 0.9.5)

- Started with `pythonw.exe` and no streams: the v0.2.0 code exits with code 1; the fixed code answers HTTP 401.
- 475 passed, 10 skipped; ruff and mypy clean.
- Local build `MCPSiigoUnofficial-0.2.1-windows-x64.exe` (46.6 MB, stock PyInstaller bootloader; CI compiles its own). Smoke test passed except `--uninstall`, skipped because it edits the real start-at-login entry. The owner installed it and confirmed the app starts.
