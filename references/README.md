# references/

Reference material that informs the design of MCP Siigo Unofficial. Nothing in here is part of the product.

## existing_mcp/

Put an existing MCP server project here (copy the whole folder), so it can be studied as a reference.

- Its files are **not** committed to Git (see `.gitignore`), because third-party code keeps its own license and the repository is public.
- What gets committed is a written analysis: `references/existing_mcp_analysis.md`. It records what the reference does well, what we reuse as an idea, and what we do differently.
- When you add a project, tell Claude its source (URL or author) and its license.
